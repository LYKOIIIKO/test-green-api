# test-green-api

Тестовый проект для изучения [Green API](https://green-api.com/) — чат на React поверх WhatsApp API.

## Возможности

- Авторизация по `idInstance` и `apiTokenInstance`
- Список чатов и история сообщений (обновление каждые 10 секунд)
- Отправка сообщений

## Стек

React 18, TypeScript, Vite, @gravity-ui/uikit, axios, Vitest + MSW

## Запуск

```bash
npm install
npm run dev
```

Креды инстанса вводятся на странице входа.

## Тесты

```bash
npm test
```
